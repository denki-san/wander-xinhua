## 使用规则

- 每项待办使用英文文件名；文件内说明目标、范围、完成标准、阻塞项和真值来源。

- 被明确搁置的项标记为 `hold`，不能当作完成。
- 新事项先写入本目录，再开始会改变运行时、资产或发布面的实施工作。
