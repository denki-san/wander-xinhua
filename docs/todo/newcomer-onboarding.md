# Newcomer Onboarding

- 优先级：P2
- 状态：todo
- 创建：2026-07-27
- 范围：`漫步新华` 首次进入后的移动端与桌面端操作可发现性。

## 目标

首次进入闲逛状态时，用户无需阅读长说明就能理解：左下区域按住并拖动可以移动；右侧区域拖动可以转动视角。

## 方案边界

- 不默认静默常驻显示摇杆；它会破坏场景画面。
- 仅首次进入 `explore` 时，显示可跳过的 10--15 秒局部交互教学；完成或跳过后完全消失。
- 第一步在左下显示临时摇杆和手指动画，文案为“按住左下区域，拖动来走路”；以真实移动持续 0.6 秒或移动向量超过约 0.25 判定完成。
- 第二步在右半屏显示横向拖拽轨迹，文案为“在右侧拖动，转动视角”；以相机 yaw 累计变化至少 20° 判定完成。
- `?` 操作面板提供“重新观看操作引导”；`prefers-reduced-motion` 仅显示静态图标和文字。
