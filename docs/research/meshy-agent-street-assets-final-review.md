# Meshy Agent 十件街景资产终审

- Date: 2026-07-28
- Package: `meshy-agent-street-assets`
- Decision: 10/10 通过共享资产隔离验收；0/10 获得具体地点摆放授权
- Source route: 已登录 Meshy Agent 网页，不使用 API
- Runtime route: `/meshy-street-assets-qa`

## 1. 终审口径

每件资产同时对照：

1. 人工批准的 Meshy 证据图；
2. Blender canonical、侧向和细节固定机位；
3. 真实 Chrome 的 Three.js 运行时截图；
4. GLB 结构、尺寸、三角面、材质、图片、纹理、动画、骨骼和根变换；
5. 推荐观察距离、人物尺度、地面或墙面锚点。

通过只表示“可以进入地点级摆放审核”，不代表当前照片能够证明某个新华社区地点
真实存在该物体。

## 4. Meshy 路线结论

可直接保留 Meshy 网格的类别：

- 粗实体：石桩；
- 结构留白仍完整的中面网格：长椅；
- 低目标下仍可读的组合：花箱。

必须把 Meshy 降级为轮廓证据的类别：

- 细杆与枝叶；
- 薄伞面；
- 闭合箱体与投口；
- 自行车轮组、车架和篮筐；
- 需要明确墙面锚点的设备。

这些类别在两轮 Remesh 后仍出现破洞、断裂、翻折或悬浮片。正确停止条件不是继续
提高或降低 target tris，而是冻结初始证据，转入可重复的 Blender 确定性重建。

## 5. 统一管理与发布边界

10 件资产已统一进入 `/asset-library` 的
`SHARED_STREET_MODEL_ASSETS`，状态固定为 `ready`。该层是“通过隔离 QA、
等待地点证据”的共享候选库，不计入线上实例数量。

本批没有修改正式地图 registry，也没有自动摆放任何实例。进入正式场景前仍需：

- 用地点照片证明物品类型、数量和大致位置；
- 在相应 `?start=` 场景中复核方向、遮挡、碰撞和地面/墙面接触；
- 按预期实例数在目标设备重新采样性能；
- 固定同一包的 GLB SHA，禁止同时引用同名实验候选。

当前使用决策：

- 保留现有线上梧桐、路灯与 InstancedMesh 垃圾桶，不做无证据批量替换；
- 长椅、花箱、石桩、伞、外摆餐桌、自行车和空调外机等待地点照片匹配；
- 幸福里本轮继续使用其 4 类专属当前街具，不用通用候选冒充现场物件；
- 旧 `meshy-agent-street-props` 实验包不进入提交，也不与本包并存引用。
